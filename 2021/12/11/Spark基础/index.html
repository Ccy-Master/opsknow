1. spark 消费kafka python样例代码：

python代码如下：

import findspark
findspark.init()
from pyspark import SparkContext
from pyspark.streaming import StreamingContext
from pyspark.streaming.kafka import KafkaUtils

if name == “main“:
sc= SparkContext(appName=”Kafka_Spark_Demo”)
ssc= StreamingContext(sc, 60)
message= KafkaUtils.createDirectStream(ssc, topics= [‘eimrs’],kafkaParams={“metadata.broker.list”:”192.168.0.157:21007”})
words= message.map(lambda x: x[1]).flatMap(lambda x: x.split(“ “))
wordcount= words.map(lambda x: (x,1)).reduceByKey(lambda a,b: a+b)
wordcount.print()
ssc.start()
ssc.awaitTermination()
